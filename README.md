
# JSON-CSV-Converter

This repository contains a web app for converting data between JSON and CSV.

## Development

Install [Bun](https://bun.sh/), then install dependencies and start the Vite
development server:

```sh
bun install
bun run dev
```

Build the app with `bun run build`. Run `bun run preview` to preview the
production build locally, or `bun run serve` to make the preview available on
the network.
